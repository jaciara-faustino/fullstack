# Formação Full Stack JavaScript 🚀

Este repositório reúne meus estudos, exercícios e projetos práticos desenvolvidos durante a formação **Full Stack JavaScript da OneBitCode**.

O objetivo é registrar minha evolução no desenvolvimento web, consolidar os conhecimentos adquiridos e praticar boas práticas de programação e versionamento de código.

## 📚 Conteúdos estudados

### HTML5
- Estrutura básica de páginas web
- Títulos, parágrafos e formatação de textos
- Comentários HTML
- Imagens e atributos
- Links e navegação
- Organização de elementos com `div` e `span`
- Exercícios práticos

## 🛠️ Tecnologias e ferramentas

- HTML5
- Visual Studio Code
- Git e GitHub

## 📂 Organização do repositório
